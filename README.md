# Fino Catat Revamp

bantu aku rombak projek fino catat ini agar lebih modern, pertama tama baca file SKILL.md gunakan SKILL.md buat patokan design.
update :
- aku ingin ui layout yang ada di folder dashboard semua di rombak total jadi modern,

- aku ingin kedepannya userku jadi mudah untuk melakukan pacatatan keuangan,

- pertahan kan fitur (pemasukan, pengeluaran, edit pemasukan, edit pengeluaran, cetak pdf / excel, admin panel (khusus role admin))

- aku mau semua card di kasih gap sehingga garis batas card terlihat semua,

- kemarin aku di roasting soal ui katanya kurang nyaman di lihat garis tidak terlihat,

- kalau refrensi sejujurnya ingin meniru seperti BRImo tampilan minimalis modern garis terlihat dan ui ux nya mudah di pahami sehingga user bisa lansgung tau dan connect fungsi fitur ini sprti apa,

- saya harap tetap gunakan db yang sudah saya tulis (firebase) dengan apikey saya sendiri
- perbaiki juga fitur notif otomatis tiap jam 8 malam, dan notif ke semua user (yang manual), karena terakhir ku coba tidak berfungsi dan tidak mau mengirimkan notif ke hp/laptop/pc user

- aku hanya ingin kode ku di update bukan di buat ulang.
